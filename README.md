## Overview

Polarities is a lore-focused Terraria content mod adding six original biomes and accompanying boss encounters woven into an exploration-driven narrative, hundreds of unique weapons and accessories with distinct attack patterns, and progression tiers that slot naturally between vanilla Terraria's existing bosses for seamless integration.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Terraria Polarities** delivers the features you need in a clean, intuitive package.
